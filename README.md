# little-reset-assets

Miniaturas de producto de Little Reset Co. (Etsy: LittleResetShop).

Este repositorio es publico por un motivo tecnico: el editor de anuncios de Etsy solo acepta
imagenes traidas desde un origen que responda con cabeceras CORS, y `raw.githubusercontent.com`
las responde. Son las mismas imagenes que se publican en la tienda.
